Homepage Refresh

A concept redesign to improve hierarchy, reduce clutter, and strengthen trust — validated through remote moderated usability testing.

← Back to Projects View Wireframe
Figma Zoom Testing Heuristic Evaluation Competitive Analysis

Project Details

  • Role UX Researcher & UI Designer
  • Tools Figma, Google Docs, Zoom
  • Users 5 participants (remote)
  • Focus Hierarchy, CTA clarity, trust

Overview

The original homepage contained competing promotions and unclear hierarchy, making it harder for users to quickly start a flight search. This refresh prioritizes a clear primary action, stronger layout structure, and trust cues to reduce hesitation.

Problem

  • Cluttered layout with competing sections
  • Weak visual hierarchy + CTA competition
  • Trust signals not obvious at key decision moments

Goals

  • Make flight search the clear #1 action
  • Improve scanability with spacing and alignment
  • Keep promos, but reduce noise
  • Strengthen perceived credibility

Process

I combined evaluation methods with usability testing to validate design decisions.

Methods

  • Competitive analysis of travel booking homepages
  • Heuristic evaluation to identify usability breakdowns
  • Remote moderated usability test via Zoom (5 participants)

Testing (Zoom)

  • Goal: evaluate clarity + what users click first
  • Tasks: initiate a flight search, find offers, identify trust cues
  • Outcome: confirmed clearer hierarchy and stronger CTA visibility

Key Design Decisions

Centralized Search

Flight search is visually prioritized to reduce friction and speed up the primary task.

Cleaner Hierarchy

Spacing, alignment, and section structure were improved to make scanning easier.

Promotion Control

Promotions were structured so they support the page without overpowering the main CTA.

Trust Signals

Credibility cues and transparency messaging were elevated to reduce hesitation.
